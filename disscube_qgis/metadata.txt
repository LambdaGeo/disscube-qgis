about=DisSCube (Declarative spatial data cubes) aggregates open sources (MapBiomas, PRODES, Brazil Data Cube, OpenStreetMap, DEMs, local files) onto one grid, declared in a TOML file. This plugin builds that file in QGIS: choose the area on the map (rectangle, layer, selected features, BDC tiles, or the grid of an existing file or raster), choose a mesh (the tiles of the BDC Grid V2, or the DisSCube default) and a resolution that nests in it, preview the grid and the tiles, add sources and variables from forms or ready-made recipes, and save the file. Three Processing algorithms (create grid, BDC tiles of an area, check grid nesting) do the same in the toolbox, the graphical modeler and batch mode. The plugin needs nothing besides QGIS; to validate and run a file it calls a DisSCube installed in another Python environment (pip install disscube).
